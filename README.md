# QuarterPomodoro

Have ever heard of the Pomodoro method?

It's easy.

Work 25 minutes, take a 5 minutes break. Work 25 minutes, again and again. until the fourth break, take this time a 30 minutes pause.

So we made this app to help you use this method.

# Don't like the rington?

You can change the file timer_finished.mp3 with your favorite ringtone!

Just keep the name and extension.

# Requirements

Have python3 installed with customtkinter and pygame installed ! The others used modules are already installed when python is installed.
